# Jelcom Information Technology Solutions Website

A responsive, single-page business website prepared for Jelcom Information
Technology Solutions and its Royal Academy of Engineering innovation application.

## Open the website

Open `index.html` in any modern web browser. The site is fully static and does not
need a server, build command, or package installation.

## Included

- Professional company overview and service catalogue
- CountrySuite flagship platform presentation
- Responsive desktop, tablet, and mobile layouts
- Accessible navigation and capability tabs
- Contact form that prepares an enquiry for WhatsApp
- Local image assets, styles, and JavaScript with no external runtime dependency

## Structure

- `index.html` - page content and metadata
- `css/styles.css` - visual design and responsive rules
- `js/main.js` - navigation and interactive behaviour
- `assets/` - company and product images

Before public deployment, review the company contact details and replace or add
any preferred email address, social profile, analytics, or hosting configuration.
